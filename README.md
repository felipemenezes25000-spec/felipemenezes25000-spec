```
 De dia  →  Reduzo MTTR em um dos maiores bancos da América Latina
 De noite →  Construo tecnologia que renova receitas para o SUS
```

Sou **engenheiro de confiabilidade** no **BTG Pactual** e **fundador** da **RenoveJá+** — uma plataforma de telemedicina **gratuita para o SUS** com **patente brasileira** de renovação digital de receitas.

No banco, lidero gestão de incidentes críticos com automação inteligente e IA. Na healthtech, construo um sistema full-stack que conecta médicos e pacientes para renovação de receitas de uso contínuo, com assinatura digital ICP-Brasil e compliance LGPD.
